## DEFECT 1 -- yoga catalogue never enumerated (P-030, self-inflicted)

`yoga_fired` takes an id from a closed set (adhi, nipuna, kendra_trikona_1_5...).
The prompt said 'ONLY ids in the detector's catalogue' and NEVER LISTED IT, so
the model could not guess one: `yoga_fired` used ZERO times on a yoga question.
FIX: `predicates.yoga_catalogue(facts)` = fired + ruled_out (exhaustive by
construction); `vocabulary_prompt(facts)` enumerates it; `interpret()` takes
`chart_facts=`; `pipeline` passes it. No catalogue -> the prompt FORBIDS yoga
predicates rather than inviting invented ids.

## DEFECT 2 -- unfittable over-used, 9 of 15 predicates

Its own notes said 'not provided in chart facts' -- the model was checking the
FACT BLOCK instead of stating the VERSE's condition. Most were expressible:
  - 'Saturn, Mars and 10th lord all in the 7th' -> 3x planet_in_house
    (would have been CONTRADICTED, i.e. correctly dropped; instead shipped hedged)
  - 'dignity of the 10th lord not provided' x3 -> planet_dignity (Mercury IS in the block)
  - 'benefic occupancy of angles' x2 -> repeated planet_in_house
Genuinely unfittable: Karakamsa and combustion only.
FIX, three prompt rules: a compound condition is SEVERAL predicates, ANDed, with a
worked 3-predicate example; judge expressibility against the VOCABULARY, never
against the facts; `unfittable` is ONLY for a concept with no predicate type
(Karakamsa, Arudha, combustion, planetary war, shadbala, avasthas, special lagnas,
degrees, orbs).
